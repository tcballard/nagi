# Credits

Nagi is written in Rust and uses GTK4 and WebKitGTK through gtk-rs and webkit6-rs.
Those libraries retain their own licences; Cargo.lock records the exact Rust dependencies.

The product direction is inspired by [Search](https://github.com/driceroland/Search)
by Office Commun: a quiet interface, lazy restored tabs and local state. Nagi's
implementation is new; no Search source or artwork is included. Search's name
and icon are not used. Reference files inspected: Session.swift blob
